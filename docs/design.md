# DoneBot Mobile

视觉：沿用桌面 Daylight / Midnight 的中性色、Geist 字体、细分隔线、圆角与品牌标记；小屏幕保持安静、紧凑和明确。

内容：登录 → Bot 列表 → 当前 Bot 主会话。电脑 / Cloud 作为列表分组和会话副标题；不展示未开通 Cloud，不提供开通、充值、模型配置或 Bot 管理。

交互：列表到会话使用短淡入；消息到达轻量浮现；账号和通知选项以底部面板呈现。遵循减少动态效果设置。

保持 44px 以上触控区域，输入文字至少 16px，适配安全区域、软键盘、横屏和平板。发送失败保留草稿与同一请求 ID，禁止后台自动重发收费任务。
