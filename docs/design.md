# DoneBot Mobile

视觉：沿用桌面 Daylight / Midnight 的中性色、Geist 字体、细分隔线、圆角与品牌标记；小屏幕保持安静、紧凑和明确。

内容：登录 → Bot 列表 → 当前 Bot 主会话。电脑 / Cloud 通过标题下的下拉菜单切换，作为会话副标题；不展示未开通 Cloud，不提供开通、充值、模型配置或 Bot 管理。

交互：列表到会话使用短淡入；消息到达轻量浮现；左上角菜单提供聊天、自动化工作与设置入口。菜单使用底部面板，设置与工作列表使用全屏页面。遵循减少动态效果设置。

保持 44px 以上触控区域，输入文字至少 16px，适配安全区域、软键盘、横屏和平板。发送失败保留草稿与同一请求 ID，禁止后台自动重发收费任务。


列表去掉品牌标志；主协调 Bot 的动画头像居中，普通 Bot 与群聊按桌面部门顺序分组。Bot 行沿用桌面侧栏的头像、名称、最后一条 Bot 回复、日期、选中背景和小圆点未读提示，不用后续用户消息覆盖回复摘要。群聊组合成员头像，群消息保留实际发言 Bot 的名称与头像。头像复用桌面造型、渐变配色、钢制素材及自定义图片裁剪 / 缩放 / 焦点，不生成随机颜色或用 emoji 替代。列表、会话标题和消息作者均使用相同头像；造型头像保留空闲眨眼与工作动画，复用桌面共享时钟，在离屏、后台和系统减少动态效果时停止不必要的动画。

图片、视频、音频及纯文本直接显示在会话中，文档仅显示图标与文件名，不使用附件外框或会话内操作栏。点开媒体后以黑底全屏显示，底部三个图标分别用于转发 / 分享、保存、用其他应用打开。PDF / Office 等文档在 iOS 中交给系统预览。iOS 的“保存”选择“文件”位置；系统分享菜单提供已安装且支持该格式的应用，以及系统提供的图片 / 视频保存操作。格式兼容性由系统和目标应用决定。

登录并连接到自己的电脑 / Cloud 后，Bot 已回复的附件直接读取，不提供额外的附件授权开关。

工作空间标题旁显示在线绿点，连接正常时不另显示“已连接”状态栏。居中的主协调 Bot 头像为 60px。普通列表提供紧凑、标准、宽松三档密度，在本机保存选择。聊天隐藏工具活动和执行摘要，保留原始历史与正常消息。

设置包含列表密度、已连接的应用程序、电脑与 Cloud 列表、自动化工作和账号 / 消息存储选项。应用列表按当前工作空间读取，只展示连接状态和账号别名；电脑与 Cloud 列表可以切换当前工作空间。自动化显示定时工作、外部事件、应用事件及所属 Bot，允许开启或关闭，离线时禁用开关；创建和内容编辑仍在电脑端完成。

输入框附件按钮提供拍摄与图库选择，最多 8 张，每张 10 MB，支持仅图片消息。附件草稿按电脑 / Cloud、Bot 和会话隔离，上传和发送分别复用请求 ID。手机保持不创建 Bot、不开通 Cloud。
